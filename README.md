# Aman Punetha — Portfolio

Personal portfolio website showcasing my work, articles, and the systems I build.

## About Me

I'm a backend-focused software engineer who designs scalable systems and cloud-native applications. I work with APIs, distributed workflows, and automated data pipelines — and I'm currently exploring AI-driven workflows where backend systems integrate with large language models.

## Tech Stack

- **React** — component-based UI
- **TypeScript** — type-safe JavaScript
- **Vite** — fast dev server and build tool
- **CSS** — custom styles, no frameworks

## Project Structure

```
src/
  components/
    Navbar/       — responsive navigation with hamburger menu
    Hero/         — intro section with avatar and bio
    Articles/     — horizontal scrolling article cards
  assets/         — images
  App.tsx         — root component
  index.css       — global styles and theme variables
```

## Getting Started

```bash
npm install
npm run dev
```
